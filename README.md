# Ruang UKDI

Aplikasi latihan soal kedokteran berbasis HTML, CSS, dan JavaScript. Buka index.html langsung di browser atau sajikan folder dengan server statis.

Fitur: latihan dengan pembahasan, simulasi berwaktu, pencarian bidang, daftar ulang soal salah, penanda, catatan dan cadangan progres di browser.

Versi awal berisi 27 kasus Paket 1 dengan pembahasan dan 31 rujukan. Impor seluruh soal sedang dilanjutkan. Kunci buku dipisahkan dari jawaban yang diperiksa referensinya. Soal ambigu atau lama tidak dihitung dalam skor terverifikasi.

PDF buku asli, gambar scan, file OCR, data progres pribadi dan kredensial tidak disertakan. Materi bukan bank soal resmi UKMPPD dan belum ditelaah dokter pengampu.
