# Ruang UKDI

Website belajar mandiri berbahasa Indonesia. Buka index.html atau jalankan server statis. Data dan progres belajar tersimpan di perangkat.

## Cakupan

- 595 soal utuh yang terbaca: Paket 1 (198), Paket 2 (200), Paket Prediksi (197).
- Paket 1 nomor 137–138 tidak ditemukan pada PDF sumber.
- Paket Prediksi nomor 186–188 tidak dapat dipulihkan karena bagian bawah halaman PDF 243 rusak; isi tidak ditebak.
- 27 pembahasan awal memiliki referensi pendukung; 21 dapat digunakan untuk penilaian. Belum ditelaah dokter pengampu.
- Soal tambahan merupakan transkripsi OCR yang dapat memuat salah eja, angka, simbol, tabel, atau redaksi. Belum semua diperiksa secara visual maupun medis. Pengelompokan bidang tambahan menggunakan kata kunci otomatis.
- Kunci/pembahasan buku lama dipisahkan dari jawaban yang diperiksa referensinya. Kunci sumber bukan rekomendasi klinis terkini.
- Paket Prediksi tidak memiliki bagian kunci dalam PDF. Paket 1 nomor 185 membutuhkan gambar EKG dan tidak mempunyai kunci huruf yang terbaca; ditandai di aplikasi.
- PDF asli, scan, dan gambar buku tidak disertakan.

## Fitur

Pencarian dan filter paket/bidang, bank soal dengan halaman, latihan, simulasi terbatas pada jawaban yang diperiksa, penanda, catatan, pengulangan, serta ekspor/impor progres lokal.

## Validasi

595 ID unik; 5 pilihan terisi per soal utuh; nomor yang tersedia cocok dengan cakupan; tautan referensi internal valid; JavaScript diperiksa sintaksnya. Pemeriksaan struktur ini tidak menyatakan seluruh transkripsi dan jawaban sudah benar secara medis.
